Hosting on GitHub Pages

  1. Save the file: Save the code above as index.html on your computer.
  2. Create a GitHub repository: Go to GitHub, create a new public repository (e.g., named news-dashboard).
  3. Upload index.html: Upload your index.html file to the root of the repository.
  4. Enable GitHub Pages: Go to your repository's Settings > Pages. Under Build and deployment, set the source branch to main (or master) and folder to / (root), then click Save.
  5. View your live dashboard: After a minute, GitHub will publish your site at https://<your-username>.github.io/<repo-name>/.
